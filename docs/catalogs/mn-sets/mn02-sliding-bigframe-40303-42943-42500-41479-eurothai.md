# MN set manual 2 - big-frame sliding (40303 / 42943 / 42500 / 41479 / EURO THAI)

**Source:** `MN_2. ชุดบานเลื่อนชุดใหญ่ MN-40303, MN-41479, EURO THAI.pdf` (24 pages, scanned). **Data:** `mn02-...json`.

## What it is
This is MN's installation guide for big-frame sliding doors. Each layout has a profile/hardware page followed by an installation-section page.

**It has no cut formulas, glass formulas, hardware quantities or prices, so the cut formula count is 0.** The JSON records each printed section dimension instead.

All the conventional sashes share the same members:
- top rail M42884 (66.2x35);
- bottom rail M42883 (79.5x35);
- lock stile M43269 (63.5x38);
- interlock M42880 (48x38);
- centre stile M41135 (71.5x38).
