# MN set manual 3 - EURO 4" sliding MN-7464 / MN-7463

**Source:** `MN_3. ชุดบานเลื่อนยูโร U7463, MN-7464 (EURO4).pdf` (20 pages, scanned). **Data:** `mn03-sliding-euro4-7464-7463.json`.

## What it is
This is MN's installation guide for the "ชุดยูโร" crimped-frame sliding system. The only assembly rule it prints is **"การประกอบทั้งวงและบานเป็น 45°"**: the frame and the sash are both mitred at 45°.
- Frame corners use the corner key Y20M03-HLD (14x26).
- Sash corners use the plate CZ-AU01 (65 mm).

**No cut formulas, glass formulas, quantities or prices are printed, so the cut formula count is 0.**
