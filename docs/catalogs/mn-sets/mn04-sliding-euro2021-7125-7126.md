# MN set manual 4 - EURO2021 sliding MN-U7125 / MN-U7126

**Source:** `MN_4. ชุดบานเลื่อนยูโร MN-U7125, MN-7126 (EURO2021).pdf` (24 pages, scanned). **Data:** `mn04-sliding-euro2021-7125-7126.json`.

## What it is
This is MN's installation guide for the EURO2021 crimped-frame sliding system. The guide prints that **the frame and the sash are both assembled at 45°**.
- Frame corners use the corner key Y20M03-HLD (14x29).
- Sash corners use CZ-AU01 plus มุมบาน B21.

The sash set (M30087 90x38 + glazing channel M30090 + interlock add-on M30088) is the same one EURO THAI uses (manual 2).

**No cut formulas, glass formulas, quantities or prices are printed, so the cut formula count is 0.**
