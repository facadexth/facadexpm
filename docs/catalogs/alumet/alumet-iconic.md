# ALUMET ICONIC (33 pages) — shortened reprint of ICONIQ Euro

**What it is:** the same ICONIQ Euro Series content as the 2024 catalogue but without the section-list and profile pages. It has only the spec pages, functionality pages and shop drawings (sliding p5-10, casement p21-26, fixed p30-31), plus colours (p32-33). p6 is blank.

- Series: sliding, casement & awning, fixed. The app types and frame sizes are the same as in `alumet-iconiq-euro-2024.md`.
- **No die tables, no kg/m, no cut formulas.** The JSON lists the assemblies with page numbers mapped back to the 2024 book and leaves `profiles` empty on purpose. Use the 2024 file for profile data.
- One difference: the drawing "บานเลื่อนสลับ ต่อช่องแสงบน" (2024 p26) is not in this print.
