## Questions for the owner (from the extraction)

1. Iconiq ไม่มีสูตรตัดในแคตตาล็อก มีแค่ระยะในแบบตัด (เช่น 18/7/11.5/80) — ขอคู่มือสูตรตัดจาก Alumet (Line @alumethub) ได้ไหม
2. เฟรมบนกับเฟรมล่างบานเลื่อนใช้รหัสเดียวกัน iS-0101 — ในแอปให้ผูกเป็น 2 บทบาทจาก 1 เส้นได้ไหม
3. กรอบบานเลื่อนมี 4 แบบ (1.5 / 2.0 / ร่อง 9.5 / ร่อง 12.7) — ค่าเริ่มต้นเราใช้แบบไหน
4. iS-0122 รางล้อ พิมพ์น้ำหนัก 0.161 kg/m เท่ากับ iS-0120 — น่าจะพิมพ์ผิด ขอตรวจกับใบราคา
5. ความยาวเส้นมาตรฐาน Iconiq ไม่ได้พิมพ์ (Alumet รุ่นอื่นใช้ 6.4 ม.) — ยืนยัน
6. น้ำหนัก Pro Smart เป็นช่วง กก./เส้น (เช่น 6.12-7.56) กว้างมาก — ใช้ค่ากลาง, ค่าต่ำ หรือค่าสูง ในการคิดต้นทุน
7. สูตรตัด Pro Smart / บานเฟี้ยม มีแค่ใน QR code — ช่วยสแกนดาวน์โหลดไฟล์มาให้ได้ไหม
