# Alumet PRO Mini Catalogue — Aluminium Profile (47 pages, scanned)

**What it is:** Alumet's standard Thai profile range with **weight tables in kg per bar** (mostly 6.4 m) for each wall thickness, with separate anodize and powder-coat columns. 137 profiles in total. The JSON keeps every thickness row as printed (`weights_by_thickness`). `kg_per_m` is *derived* (anodize midpoint of the first thickness ÷ bar length, marked estimated).

**Cut formulas printed (the only Alumet book that has them):**
- Standard sliding (p11): sash h = H − 28; sash w = (W − 14.14)/n + 17.15 (interlock 34.3)
- Big-frame sliding (p12): h = H − 24; w = (W − 45)/n + 25.5 (stile 48)
- Standard casement in a 4" box (p22): inner opening = outer − 124.9 each way (62.45 per side). Printed "H=h-124.9", with the letters swapped.
- Union casement (p23): h = H − 58; w = W − 54
- Swing door pair (p27): h = H − 69; w = (W − 88.9)/n − 5.5. Where the bracket goes is unclear.

**Could not resolve:** the meaning of "Over/Under" thickness grades. Drawing dies 4019-4023, 5004, 5009 and 020036-020049 have no weight row. No prices.
