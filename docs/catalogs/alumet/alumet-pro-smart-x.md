# Alumet PRO SMART X (27 pages)

**What it is:** Alumet's newer 1.2-1.5 mm "Smart X" system for low-rise houses: sliding, casement/awning and fixed. It gives die no., name and section dimensions, but **no weights**. Data: `alumet-pro-smart-x.json` (36 profile rows).

**Assembly (drawings only):**
- Sliding sash: lock stile SS-X201, interlock = SS-X201 + clip-on SS-0139, rails SS-X203. Glass groove is 16; the SS-X204 insert makes it 9.5. Plan dims: jamb 25 + 4, stile 63, interlock 63.5.
- Casement: 25 / 7 / 11.5 / 80, the same geometry as ICONIQ.

**Hardware (p9):** SLM001 lock-stile cap, SLM004 buffer, SLM005 wind seal, DWM006/DWM007 drain caps, SLM022 keeper, SLM0XX hook.
**Accessories (p16):** bubble gasket, 2x2" aluminium corner angles (6 mm and 3 mm), stainless corner braces.
**Pages to look at:** p3 (section list), p6-8, p14-15, p22 (profiles), p10-11, p17-19, p23-24 (drawings).
**Not in the book:** kg/m, cut formulas, prices. The weight "1.25-1.45 / 1.30-1.50" printed under SC-X103 probably belongs to the bead SF-0102.
