# Rich menu ของ LINE OA ลูกค้า (@facadex)

ไฟล์ในโฟลเดอร์นี้:

- `customer-richmenu.html` ต้นฉบับภาพเมนู ขนาด 2500×1686 px
- `customer-richmenu.png` ภาพที่เรนเดอร์แล้ว สำหรับอัปโหลดใน LINE OA Manager

**ข้อควรจำ:** ไฟล์ PNG ต้องมีขนาดไม่เกิน 1 MB (ข้อจำกัดของ LINE)

## 1. ตั้งค่า Rich menu ใน LINE OA Manager

เมนู Rich menus > Create

1. ตั้งชื่อเมนูตามต้องการ (ใช้ภายในเท่านั้น)
2. Menu bar text: `เมนู`
3. Display period: แสดงตลอด (ไม่กำหนดวันสิ้นสุด)
4. เลือก template **Large · 6 areas (3×2)**
5. อัปโหลด `customer-richmenu.png`
6. ตั้ง action ของแต่ละพื้นที่เป็น **Text** โดยใส่ข้อความตามตารางนี้ เรียงจากซ้ายไปขวา บนลงล่าง ต้องพิมพ์ให้ตรงทุกตัวอักษร

| พื้นที่ | ตำแหน่ง | ข้อความ (Text) |
|---|---|---|
| A | บนซ้าย | ขอใบเสนอราคา |
| B | บนกลาง | สถานะงาน |
| C | บนขวา | แจ้งซ่อม |
| D | ล่างซ้าย | สถานะแจ้งซ่อม |
| E | ล่างกลาง | ประกันของฉัน |
| F | ล่างขวา | ติดต่อเรา |

7. เปิดสวิตช์ให้เป็นเมนูเริ่มต้น (default menu) แล้วกดบันทึก

## 2. ตั้งค่า Webhook ใน LINE Developers

1. เปิดแอป CHANG ที่ ตั้งค่า > การสื่อสารและแจ้งเตือน > การ์ด "LINE OA ลูกค้า" แล้วคัดลอก Webhook URL (การ์ดหัวข้อ "เชื่อม LINE OA ของบริษัท (สำหรับลูกค้า)")
2. ใน LINE Developers Console เลือก Provider และ channel ของ @facadex ไปที่แท็บ Messaging API
3. วาง URL ในช่อง Webhook URL แล้วกด Verify
4. เปิด **Use webhook**
5. กลับมาที่แอป กดปุ่ม "ทดสอบการเชื่อมต่อ" ในการ์ดเดิม ต้องขึ้น "ทดสอบผ่าน"

## 3. Response settings ใน OA Manager

เมนู Settings > Response settings

- Chat: **เปิด**
- Auto-reply messages: **ปิด** (ถ้าเปิด บอทจะตอบซ้ำกับข้อความจากเมนู)
- Greeting message (ข้อความทักทาย): **ปิด** บอทส่งข้อความต้อนรับเองเมื่อลูกค้าเพิ่มเพื่อน (ถ้าเปิดทั้งคู่ ลูกค้าจะได้รับคำทักทาย 2 ครั้ง)

## 4. ข้อความที่บอทตอบ

ลูกค้าต้องส่งรหัสเชิญ 6 ตัวที่ได้จากบริษัทมาก่อน ระบบจึงจะเชื่อมไลน์นั้นกับงานของลูกค้า

- ปุ่มที่ต้องเชื่อมบัญชีก่อน: สถานะงาน, แจ้งซ่อม, สถานะแจ้งซ่อม, ประกันของฉัน ถ้ายังไม่เชื่อม บอทจะตอบข้อความต้อนรับ: "สวัสดีครับ ขอบคุณที่เพิ่มเพื่อน (ชื่อแบรนด์) 🙏" ตามด้วย 2 ข้อ คือ (1) เป็นลูกค้าอยู่แล้วให้ส่งรหัสเชิญ 6 ตัวที่ได้จากเจ้าหน้าที่ (2) สนใจงานใหม่ให้กด "ขอใบเสนอราคา" ชื่อแบรนด์ใช้ชื่อที่แสดงของ OA (display_name) ถ้าไม่ได้ตั้งจะใช้ชื่อบริษัท
- ข้อความต้อนรับนี้ส่งเมื่อลูกค้ายังไม่เชื่อมบัญชีเพิ่มเพื่อน (ลูกค้าที่เชื่อมแล้วเพิ่มเพื่อนซ้ำจะไม่ได้รับ) และส่งเมื่อคนที่ยังไม่เชื่อมบัญชีพิมพ์ข้อความทั่วไปที่ไม่ใช่คำสั่งหรือรหัส แต่ส่งไม่เกินวันละ 1 ครั้งต่อคน (ตามวันที่เวลาไทย) ครั้งอื่นบอทเงียบเพื่อให้เจ้าหน้าที่คุยเอง
- ปุ่มที่ใช้ได้กับทุกคน: ขอใบเสนอราคา, ติดต่อเรา

ตารางนี้สรุปเฉพาะ Phase 1a ข้อความจริงอยู่ใน `supabase/functions/_shared/customer-line-replies.ts`

| ปุ่ม | ข้อความ | บอทตอบ (สรุป) |
|---|---|---|
| ขอใบเสนอราคา | ขอใบเสนอราคา | ขอบคุณที่สนใจ ให้ส่งแบบหรือรูปหน้างาน ขนาดคร่าวๆ ที่ตั้งหน้างาน และเบอร์โทร เจ้าหน้าที่จะติดต่อกลับโดยเร็ว |
| สถานะงาน | สถานะงาน | แสดงงานที่กำลังดำเนินการหรือพักไว้ (สูงสุด 10 งาน) พร้อมความคืบหน้ารวม %, ช่วงงานที่กำลังทำ และกำหนดเสร็จ ถ้าไม่มีงานที่ดำเนินอยู่ จะตอบ "ขอบคุณที่ไว้วางใจ (ชื่อแบรนด์) ครับ 🙏 ตอนนี้ยังไม่มีงานที่อยู่ระหว่างดำเนินการ" พร้อมแนะนำให้กด "ประกันของฉัน" สำหรับงานที่ส่งมอบแล้ว หรือ "ขอใบเสนอราคา" สำหรับโครงการใหม่ นอกจากนี้ส่งรูปที่ทีมติ๊ก "ให้ลูกค้าเห็น" ให้อีกไม่เกิน 3 รูป เฉพาะเมื่อลูกค้ามีงานที่ดำเนินอยู่เพียง 1 งาน |
| แจ้งซ่อม | แจ้งซ่อม | ให้พิมพ์อาการและส่งรูปในแชทนี้ เจ้าหน้าที่จะรับเรื่องและติดต่อกลับ (ข้อความชั่วคราว) |
| สถานะแจ้งซ่อม | สถานะแจ้งซ่อม | ยังไม่มีรายการแจ้งซ่อมในระบบ ถ้าแจ้งทางแชท เจ้าหน้าที่จะตอบในแชทนี้ (ข้อความชั่วคราว) |
| ประกันของฉัน | ประกันของฉัน (พิมพ์คำเหล่านี้ก็ได้: ประกัน, รับประกัน, ระยะเวลารับประกัน, เช็คประกัน, ตรวจสอบประกัน ช่องว่างไม่มีผล แต่ต้องตรงทั้งคำ) | ตอบเป็นการ์ด LINE (Flex carousel) เลื่อนดูทีละงาน สูงสุด 10 งาน ข้ามงานที่ยกเลิก หัวการ์ดมีสีตามสถานะ: เขียว "อยู่ในประกัน" (มีแถบแสดงเวลาที่ใช้ไป และ "เหลืออีก N วัน" ถ้าน้อยกว่า 60 วัน ไม่เช่นนั้น "เหลือประมาณ N เดือน"), เทา "หมดประกันแล้ว", เหลือง "ยังไม่ส่งมอบงาน", เทา "ไม่มีระยะประกัน" (ระยะประกัน 0 เดือน ตอบแบบนี้ไม่ว่าส่งมอบแล้วหรือยัง) ตัวการ์ดแสดงชื่องาน วันส่งมอบงาน และวันประกันถึง เป็น วว/ดด/ปปปป (พ.ศ.) พร้อมประโยคปิดท้าย ท้ายการ์ดมีปุ่ม "แจ้งซ่อม" และ "ติดต่อเรา" ที่ส่งข้อความเข้าแชท ข้อความแจ้งเตือนบนหน้าจอ (altText) เป็นข้อความธรรมดาแบบเดิม ไม่เกิน 400 ตัวอักษร ถ้าไม่มีงานในระบบเลยจะตอบข้อความ "ยังไม่มีงานในระบบ" ไม่แสดงเงิน คนงาน หรือบันทึกภายใน |
| ติดต่อเรา | ติดต่อเรา | ชื่อบริษัท เบอร์โทร และเวลาทำการ (ถ้าตั้งค่าไว้) ตามด้วยบอกให้พิมพ์ในแชทได้เลย เจ้าหน้าที่จะตอบในเวลาทำการ |

ข้อความอื่นที่เกี่ยวข้อง

- ส่งรหัสเชิญถูกต้อง: "เชื่อมกับ (ชื่อลูกค้า) เรียบร้อยครับ" และบอกให้กดเมนู "สถานะงาน"
- ส่งรหัสเชิญไม่ถูกต้องหรือหมดอายุ: ให้ขอรหัสใหม่จากบริษัท ข้อความนี้ตอบเฉพาะคนที่ยังไม่เชื่อมบัญชี ถ้าลูกค้าที่เชื่อมแล้วพิมพ์คำอังกฤษ 6 ตัวอักษร บอทจะไม่ตอบอะไร

## 5. รูปภาพและไฟล์จากลูกค้า

ข้อความ "แจ้งซ่อม" และ "ขอใบเสนอราคา" ขอให้ลูกค้าส่งรูปหรือแบบมาในแชท แต่บอทยังไม่อ่านหรือเก็บรูป (ข้อความที่ไม่ใช่ตัวอักษรจะถูกข้าม) รูปและไฟล์ที่ลูกค้าส่งมา เจ้าหน้าที่จะเห็นในแชทของ LINE OA Manager เท่านั้น และยังไม่ถูกบันทึกในแอปเป็นใบแจ้งซ่อม ส่วนนั้นจะทำใน phase ถัดไป จึงต้องเปิด Chat ไว้ตลอด
