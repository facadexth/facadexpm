Mockup: ภาพด้านหน้า (elevation) ของแต่ละ type ในแคตตาล็อก เปลี่ยนตัวเลขแล้วภาพวาดใหม่ทันที ความกว้างของชิ้นอลูมิเนียมในภาพเป็นค่าตัวอย่าง ในแอปจริงอ่านจากหน้าตัดโปรไฟล์ที่เลือก สัญลักษณ์การเปิดใช้ตามธรรมเนียมแบบสถาปัตยกรรม (ดูกล่องอ้างอิงด้านล่าง)

วงกบ / เฟรม / เสาแบ่ง (เส้นคู่) กรอบบาน (บานเปิด บานเลื่อน บานประตู) กระจก กระจกบานติดตาย (F) — — V = ด้านแหลมคือด้านบานพับ · เส้นทึบ = เปิดเข้าหาผู้มอง · เส้นประ = เปิดออกจากผู้มอง · ลูกศร = ทิศเลื่อน

ธรรมเนียมการเขียนแบบที่ใช้ในภาพ (อ้างอิงจากอินเทอร์เน็ต)

  • บานเปิด / บานสวิง / บานกระทุ้ง: เส้นทแยงสองเส้นบรรจบเป็นรูป V ตื้น ๆ พาดบาน ปลายแหลมอยู่ด้านบานพับ บานเปิดข้าง = แหลมที่วงกบข้าง บานกระทุ้ง (บานพับบน) = แหลมที่ด้านบน บานกระทุ้งล่าง (hopper) = แหลมที่ธรณี · เส้นทึบ = บานเปิดเข้าหาผู้มอง เส้นประ = เปิดออกจากผู้มอง (ภาพเดียวกันจึงกลับกันเมื่อดูจากในหรือนอกอาคาร) — learnarchitecture.online, planacad.com, Wikipedia: Casement window
  • บานเลื่อน / รางแขวน: ลูกศรบนบานบอกทิศที่เลื่อน บานติดตายเป็นสี่เหลี่ยมไม่มีสัญลักษณ์ (ในแบบมักเขียน F) — smallhouseplan.com, illustrarch.com
  • บานเฟี้ยม: แต่ละบานมี V สลับด้านเพราะบานพับต่อกันเป็นคู่ ปลายลูกศรบอกด้านที่พับเก็บ (ตีความจากธรรมเนียมบานเปิด ไม่พบมาตรฐานเดียวที่ทุกสำนักใช้ตรงกัน)
  • Curtain wall: ภาพด้านหน้าเป็นตารางเสา (mullion) แนวตั้ง และราว (transom) แนวนอน ช่องที่เป็นกระจกมองทะลุ (vision) กับช่องทึบ (spandrel) แยกด้วยสีเติม แบบ unitized วาดรอยต่อยูนิตเพิ่ม — ideCAD curtain wall
  • บานเปลือย (frameless): ไม่มีกรอบอลูมิเนียม แสดงเป็นกระจกชนกันเว้นร่องซิลิโคน บานสวิงเปลือยมี patch fitting ที่มุมบน-ล่าง (วาดเป็นสี่เหลี่ยมเล็ก)
